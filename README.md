# 🔗 ConnectIQ — Social Network Recommendation System

ConnectIQ is a Python-based project that analyzes **social network data** to explore user relationships and generate recommendation-oriented insights such as **People You May Know** and **Pages You Might Like**.

## 🎯 Features

* 🧹 Data cleaning and preprocessing
* 👥 People You May Know recommendations
* 📄 Pages You Might Like recommendations
* 📊 Analysis of user relationships and interests
* 📂 Processing of JSON datasets

## 🛠️ Technologies

* **Python**
* **Jupyter Notebook**
* **JSON**
* **Git & GitHub**

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/heyeshaa/connectiq.git
cd connectiq
```

Install Jupyter:

```bash
pip install notebook
```

Start Jupyter:

```bash
jupyter notebook
```

Open the notebooks and run the cells in order.
